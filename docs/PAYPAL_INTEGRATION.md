# PayPal Integration Summary

## Overview
Implemented PayPal integration using Guzzle and Slim framework.

### Added Files
- **src/Service/PayPalGateway.php** – Service class handling OAuth token retrieval, order creation, capture, and webhook signature verification.
- **src/Controller/PayPalController.php** – Slim controller exposing two API endpoints:
  - `POST /api/payments/paypal/create` – creates a PayPal order.
  - `POST /api/payments/paypal/execute` – captures a previously created order.
- **web/webhooks/paypal.php** – Webhook endpoint that validates PayPal signatures using `PayPalGateway::verifyWebhook`.

### Environment Variables
- `PAYPAL_CLIENT_ID`
- `PAYPAL_CLIENT_SECRET`
- `PAYPAL_WEBHOOK_ID` (used for webhook verification)

### Routes Registration (example)
```php
$app->post('/api/payments/paypal/create', [\App\Controller\PayPalController::class, 'create']);
$app->post('/api/payments/paypal/execute', [\App\Controller\PayPalController::class, 'capture']);
```

### Webhook Setup
Place `paypal.php` under `web/webhooks/`. Configure your PayPal app to point to this URL and set the same **PAYPAL_WEBHOOK_ID** in the environment.

### Usage
1. Ensure Composer dependencies include `guzzlehttp/guzzle` and Slim.
2. Set the required environment variables.
3. Call the create endpoint with JSON body `{ "amount": 19.99, "currency": "USD", "returnUrl": "...", "cancelUrl": "..." }`.
4. After buyer approval, call the execute endpoint with `{ "orderId": "..." }`.
5. PayPal will POST events to `/web/webhooks/paypal.php`; the script validates the signature and returns a 200 response on success.

## Notes
- The gateway caches the OAuth token until just before expiration.
- Webhook verification requires the registered PayPal webhook ID.
- Adjust autoload namespaces if your project uses a different PSR‑4 root.
